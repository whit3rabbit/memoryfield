ROADMAP.md 4.3 (multi-writer): decided page slug = filename stem (mf/page.py's Page.slug), since that's what two writers actually collide on -- each writer mints its own uuid independently, so uuid can't be the collision signal, but two agents drafting a page for the same topic tend to pick the same descriptive filename. Built mf claim SLUG --by WRITER (mf/claim.py): an atomic INSERT INTO claims ... ON CONFLICT(slug) DO NOTHING, which is safe across processes because SQLite serializes writers at the file level -- a second process's insert blocks until the first commits, then sees the conflict. Exit 0 if the caller now holds the slug (won, or already held it -- re-claiming your own slug is a no-op success), exit 2 if someone else does, mirroring write's dedup-gate exit-code convention. contested needed no new plumbing since it was already a valid status value handled generically everywhere; what it needed was a trigger, so mf lint now warns contested-slug when two active pages share a slug. write does not call claim automatically yet -- deferred until a real multi-writer collision is observed.
